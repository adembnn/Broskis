Comprendre (Lexique)
  • Lot : Une tâche précise et isolée de développement.
  • Worktree : Une copie du code sur laquelle travaille un agent pour ne pas gêner les autres.
  • Agent : Une IA autonome (comme Gemini CLI) qui accomplit un lot.
  • Fusion : Intégration du code d'un agent dans le projet principal.
  • Gemini CLI : Notre outil IA en ligne de commande pour le code.
  • Voice Design : Génération de voix expressives via l'IA Gradium.
  • Tokens : Le système de design unifié (couleurs, polices, tailles).
